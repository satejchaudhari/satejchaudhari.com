Welcome to the Log

2026-07-02 · 2 min read

This is the first entry. It exists mainly to show you the format — copy posts/post-template.html for every new post.

How the site is organized

The homepage has three sections: About, a preview of the latest writeups, and a preview of the latest blog posts. Each preview links out to its own full page:

  • writeups.html — longer, structured research and CTF walkthroughs
  • blog.html — shorter posts, field notes, and TILs
  • toolkit.html — a categorized list of tools, meant to be useful to anyone, not just me

How to add a new writeup or post

Three steps, no build tools:

  1. Copy posts/post-template.html, rename it, and write your content inside the post-body div.
  2. Open assets/js/posts.js and add one entry to the POSTS array at the top — set type to "writeup" or "blog" depending on which page it should appear on.
  3. Save and refresh. It appears on the homepage preview and on its full list page automatically.

Code blocks

Fenced code renders in a dark panel automatically:

import requests

def check_target(url):
    r = requests.get(url, timeout=5)
    return r.status_code == 200

Adding a tool to the toolkit

Open assets/js/toolkit.js and add an entry to the right category (or add a new category). The page — including the search box — rebuilds itself from that file.
