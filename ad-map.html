How to read this map

Fill colour = attack category

Each colour is a family of techniques — see the coloured chips below. Click one to spotlight that family.

Border = what kind of node

    Markers & arrows

    • ▸ prefix an entry point — you can start here with no access
    • gold ring an end goal (Domain Admin / forest)
    • → solid escalation / forward step
    • ⇢ dashed lateral move or loop-back
